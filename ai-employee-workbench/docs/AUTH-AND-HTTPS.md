# 登录与 HTTPS 维护说明

铆钉公开入口为 `https://maoding.reai.com`。Nginx 负责 HTTPS，单个应用容器负责身份与权限校验；部署模板见 [deploy/README.md](../deploy/README.md)。

## 身份与权限

登录使用 OAuth 2.0 Authorization Code + PKCE（S256），不是 OIDC：应用不接收或验证 ID Token，而是使用 access token 请求外脑 `/oauth/userinfo`，根据返回的 `sub` 识别用户。授权范围为 `profile:read` 和 `model-gateway:invoke`，分别用于身份核验和模型调用。

`WAINAO_ADMIN_SUBJECTS` 登记管理员的用户 UUID；`WAINAO_ALLOWED_SUBJECTS` 登记其他允许访问的用户，均以逗号分隔。只有显式设置 `WAINAO_ALLOW_SITE_ADMINS=true` 时，外脑返回的 `is_site_admin=true` 才能授予铆钉管理员权限。外脑团队管理员身份本身不具备此权限。用户不在适用名单中时拒绝登录。

管理员配置岗位、规范、模型、tools、MCP 与 skills，并管理结构化数据。普通允许用户可以使用岗位工作流和看板。当前是单用户工作台扩展出的共享岗位访问名单，所有允许用户访问同一组岗位数据，**不是多租户、客户或案件的数据隔离系统**。MCP stdio 配置具有容器内代码执行能力，只交给可信管理员；容器不要挂载其他项目的数据和凭据。

## 模型授权与凭据

管理员通过模型目录连接岗位后，Agent 配置只记录对应 `oauthSubject`，实际调用时才向凭据模块取得 token。模型请求固定发送到配置的外脑官方网关；修改 Agent 的 base URL 或协议不能将该 OAuth token 转发到其他地址。岗位使用连接它的账号授权，并不自动切换成每位操作者自己的账号或额度。

浏览器仅获得随机会话句柄，Cookie 使用 `HttpOnly`、`Secure`、`SameSite=Lax` 和 `__Host-` 前缀。OAuth access/refresh token 保存在服务器加密授权存储中，不放进前端、Agent 配置或路由快照。密钥与授权文件都属于私有数据卷，备份必须一并保护；这不提供对已控制宿主机或该卷的攻击者的隔离。

临近过期时刷新 token，同一账号的并发刷新合并处理。刷新失败时本地授权失效，避免重放可能已经被轮换的 refresh token。退出登录先移除本地会话和授权，再尝试撤销远端 token；接口中的 `revoked=false` 表示远端撤销未确认，不能将本地退出等同于远端撤销成功。必要时在外脑侧核对并撤销授权。重新登录会替换同一账号在本应用中的旧会话。

## 开发、审核与发布

新 OAuth 应用可在开发阶段设置 `WAINAO_OAUTH_DEVELOPMENT=true`，通过 HTTPS 完成真实授权与验收；访问者仍需具备该 OAuth 应用的开发资格，并满足铆钉身份名单。收集证据后按外脑流程提交审核。正式发布后改回 `false` 并更新应用容器。不能用开发参数绕过身份名单或管理员校验。

回调地址固定为 `https://maoding.reai.com/api/auth/callback`，必须与 OAuth 应用登记值一致。`EMPLOYEE_PUBLIC_ORIGIN` 是可信来源，服务严格核对 Host 与管理 API 的 Origin；转发头不用于扩展信任范围。管理写请求还要求工作台请求标记。Nginx 应保留 Cookie 和 `Authorization`，并避免在访问日志记录回调查询串。

## 看板与服务器目录

管理 API 使用 OAuth 会话；`/board-api` 使用仅绑定该看板数据表的 Bearer capability，不依赖 OAuth Cookie。生成 HTML 在 opaque-origin sandbox iframe 中运行，REST 请求省略 Cookie。可信父页面通过 `frame-src 'self'` 限制子页导航，生成页面通过 `frame-ancestors 'self'` 限制嵌入来源；顶层 preview 返回可信 wrapper，未直接执行生成 HTML。不要在反向代理覆盖这些 CSP/CORS 头，或给 `/board-api` 叠加 Cookie 登录检查。

公网部署后的工作目录位于服务器专属数据卷；浏览器上传才会把用户电脑上的文件导入服务器。公网创建岗位不接受任意宿主机目录。更新应用保留数据卷，历史本机数据和凭据的迁移需单独核对绝对路径及授权范围。
