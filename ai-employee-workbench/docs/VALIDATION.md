## 浏览器验证

使用 Codex 内置浏览器访问本机生产构建，创建明确标注为测试用途的工作区，资料为虚构销售样例。

- 创建岗位、扫描工作目录和浏览器文件上传成功；上传状态、原件版本与实际文件对应。
- 页面保存 Agent 配置后，Pi 向独立本地模型测试服务发送请求，清洗生成 2 条 B 记录与数据库 Schema。
- 从页面生成看板，预览 iframe 通过受限 REST API 读取真实数据库记录；确认后加入侧栏。
- 管理员将一条记录从金额 1200 修订为 1500，版本从 v1 增至 v2；重新打开看板，总额从 2000 变为 2300，证明页面读取当前 B。
- 修复窄窗口默认聊天浮层遮挡业务控件；窄窗口默认收起，用户可随时打开。
