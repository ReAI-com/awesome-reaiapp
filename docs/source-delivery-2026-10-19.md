# 插件与共享工具源码同步

验收日期：2026-10-19。所有修改和验证在独立 worktree 完成。

本次从 ReAI Board 主仓库的最新主线同步官方插件、共享工具和提交脚本。同步以 2026-10-06 的同步来源为基准做三方合并：主仓库之后的更新全部合入，本仓库已有的路径改写、示例数据脱敏、公开说明和本地修复保持不变。提交身份、内部审查材料、发布记录和构建产物不进入本仓库。

## 合并取舍

- PDF 解码扩容采用主仓库的按比例扩容方案，替代本仓库 `2.14.5-dev.3` 的小块扩容方案。累计预算、分配前拒绝和 Worker 时限不变。
- 语言工具的 Voice 回归夹具更新为平台已批准的 `2.14.6` 包摘要，仍只作为测试夹具。
- 主仓库专用的旧 SDK 兼容脚本绑定其内部提交，在本仓库无法运行，未同步。
- 主仓库 `platform/docs/` 中新增或更新的规范文档不在本次范围，`docs/` 仍为本仓库的文档事实源。
