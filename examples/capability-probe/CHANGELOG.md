# 能力探针更新日志

## 0.2.1 · 2026-10-23

### 跳到权限页之前先提示

状态：本地开发示例，未送审、未签名、未上架。

- 改进：「跳到 Driver 设置页」（含「跑完全部 17 项」的最后一项）跳走之前，探针顶部先显示 3 秒提示：要跳到本插件的权限页，到那边点右上角「返回」回来这一项才算通过；可以点「取消跳转」，取消不算一次测试。原来是直接跳走，容易以为出错了。
- 改进：跳转倒计时或进行中时，「跑完全部」「运行全部安全测试」暂时不能点，免得批量测试被跳走打断。
- 新增：「本地存储读写」卡片里加了单步验证：写入 / 查看 / 删除一条固定测试数据。查看时同时给出三处可核对的位置：插件读回的值、键列表、硬盘上的存储文件（文件夹、文件名、文件里的键名和核对码），并附一条在终端里粘贴即可让访达选中该文件的命令。这几个按钮不计入 17 项验收。
- 改进：「键盘按键触发命令」的提示补上拨杆分层的说明。真机发现：键绑在通用层，但拨杆所在那一档给同一个键另配了别的插件命令时，按下去执行的是那一档的动作（别的插件没装就提示「目标应用不在了」），探针收不到。
- 修正：「跳到 Driver 设置页」上一次没点右上角状态条的「返回」或「关闭」就从侧栏回来，再测会被 Driver 拒绝（同一时间只开一个系统任务）。原来显示「出错」，现在提示先点「返回」或「关闭」把上一次结束掉，再测一次。
- 新增：「调用 Voice 插件的服务」卡片里加了「录一句话」：开始听写 → 实时显示状态（准备中、听写中、识别中、完成）→「说完了」或「取消」→ 显示识别出的文字、请求号和识别类型。会真的打开麦克风，识别走云端、可能消耗账户额度；只在你点按钮时发起，不进「跑完全部」，不计入 17 项验收。识别文字只显示在卡片里，不保存、不写进报告。
- 改动：Voice 文字服务依赖的用途说明改为「只在你点『开始听写』时录一句话」。用途变了，装新版时需要重新确认这一项。
- 未验证：真实 Driver 上的提示效果、存储单步验证和录一句话，等真机复测。

## 0.2.0 · 2026-10-22

### 一眼看出「全部通过」没有

状态：本地开发示例，未送审、未签名、未上架。

- 新增：总览顶部的验收卡，显示「通过 N / 共 17 项」，列出没通过的项、原因和去哪一页处理；全部通过时显示「全部 17 项通过」。
- 新增：「跑完全部 17 项」按钮。先跑不打扰的，再发通知、调 Voice，最后跳到本插件的权限页。原来的「运行全部安全测试」保留。
- 修正：测试结果保存在本插件自己的存储里。「跳到 Driver 设置页」会离开插件页面，原来回来后结果全部清空；现在跳走再回来、重新打开插件都还在，「记录与报告」里可以清空。只恢复同一 Driver 版本、同一插件版本的结果，总览会写明其中几项是上次保存的，报告里这些项标 `restored`。同一探针以更晚的结果为准，清空之后旧结果不会再写回来。
- 修正：「跳到 Driver 设置页」跳走时 Driver 会关掉探针页面，调用的回执回不来。现在跳转时把一段返回信息交给 Driver，用户在权限页点右上角「返回」后，Driver 把它连同任务号带回探针，以这个回执确认跳转成功；没点「返回」回来的，这一项保持「还没测」。
- 修正：页面脚本自检等加载超时或被取消时，不再算作「按预期拦下」，改为「等你操作」并提示再测；已取消的自检立即结束，不再空等 1.5 秒。
- 修正：内部导航命令（返回首页、打开设置）不出现在键位选择器里。
- 修正：界面关掉后，它启动时的后台任务不再动跳转记录、不再继续重试读版本，避免误删下一个界面要补记的跳转结果。
- 修正：「声明式页面」示例区的刷新合并为同一时间最多一轮，不再重复读取，也不会被晚到的旧读取倒回旧值。
- 修正：诊断信息脱敏时，JSON 字段值里带转义引号也能整段隐藏，不再留下凭据尾段。
- 修正：补上 `open-settings` 命令。Driver 面包屑的「设置」出口原来因为缺这个命令不可用（日志里的 `SURFACE_NAV_COMMAND_UNDECLARED` 警告）。
- 修正：「发一条系统通知」遇到 Driver 偶发的 `NOTIFICATION_ENQUEUE_FAILED`（Driver 发通知时 macOS 主线程正忙）时，隔 1.5 秒重试一次；重试成功也会写明「第一次失败」，不掩盖问题。
- 修正：「记录与报告」的记录表改成两行布局，摘要不再被挤成一字一行。
- 修正：设置页和报告里的 Driver 版本改为界面显示出来后再读取，Driver 还没把界面记为可见时隔 1 秒重试（最多 5 次）。原来读得太早，被 Driver 以 `SYSTEM_TASK_VISIBLE_SURFACE_REQUIRED` 拒绝，显示「读取失败」。
- 修正：「被拦下」拆成两种。反例按预期被拦下显示为「按预期拦下」（绿色，算通过）；没同意权限的拦下仍是「被拦下」（算没通过）。导出报告加上每项的 `verdict`、`passed` 和总的 `acceptance` 汇总，报告格式升到 2。
- 修正：操作指引跟上新版 Driver：本地安装入口在「设置 › 开发者选项」；权限在安装弹窗里勾选，事后到「已安装」点开插件改；键位在「设备 › 键位映射 › 插件动作」。
- 修正：Voice 返回的错误码带 `com.reai.voice/` 前缀时也能认出「服务在线」。
- 修正：网络反例没被拦时，提示改为「Driver 版本较旧，请更新」。新版 Driver 对本地包一律按严格网络规则检查，「严格网络预览」开关不再影响拦截。
- 已验证：Driver 主干开发版（1.0.5，提交 438234e）上本地安装、同意权限并启用，清空结果后「跑完全部 17 项」，从权限页点「返回」回到探针，17 项全部通过（跳转一项以 Driver 带回的回执确认）；`STORAGE_NOT_DECLARED` 与两个网络反例按预期拦下。「键盘按键触发命令」用 Driver 开发版的 `--debug-app-command` 触发，没有用实体键盘按键。
- 未验证：较旧的 Driver、Windows、英文界面、没有登录时的结果。

## 0.1.1 · 2026-10-21

### 修正两项反例的判定

状态：本地开发示例，未送审、未签名、未上架。

- 修正：「没声明的存储空间（反例）」只认 Driver 新增的 `STORAGE_NOT_DECLARED` 拒绝码。较旧的 Driver 不检查存储空间是否声明，会显示「与预期不同」并提示更新 Driver。
- 修正：「访问不加密的 http 地址（反例）」如实说明拦下原因。清单只能声明 https 地址（安装时检查），所以 http 地址在运行时按「没声明的地址」拦下，不再说成是 https 检查。浏览器预览也改成和 Driver 一样的判定顺序。
- 修正：反例意外写入成功后，如果清理测试数据失败，如实写「测试数据没删掉」，不再一律声称已删除。
- 修正：开发者模式下「记录与报告」的说明改为如实提示：诊断信息会去掉已知格式的令牌，但可能含路径或个人信息，分享前请检查。
- 已验证：Driver 1.0.5 实测报告中这两项的现象（未声明存储被接受、http 地址返回 `NETWORK_ENDPOINT_NOT_DECLARED`）。
- 未验证：带 `STORAGE_NOT_DECLARED` 的新版 Driver 上的实测结果，等 Driver 改动合并后补测。

## 0.1.0 · 2026-10-21

### 第一版：本地开发包能用的能力，逐项实测

状态：本地开发示例，未送审、未签名、未上架。

- 新增：能力目录。把 Driver 插件平台的每一项能力按「免审 / 需要用户同意 / 需要平台批准 / 暂未开放」四档列出，第一行是人话，第二行是技术标识；需要批准的能力显示审核清单里已获批的插件。
- 新增：测试按钮。本地存储、键盘按键命令、调用 Voice 服务、Driver 版本、跳转设置页、是否已登录、系统通知、经 Driver 访问外脑，以及几个「应该被拦下」的反例（只认预期的拒绝原因）。「全部测试」只跑不跳页面、不弹通知、不启动别的插件的项目。
- 新增：页面脚本限制自检。在插件页面里尝试四种运行时生成代码的写法，看 Driver 是否都拦下。
- 新增：声明式页面示例。用一份 JSON 描述页面，严格检查后由插件自带的渲染器画出来，按钮只能做白名单里的事；附四个会被拒绝的反例。
- 新增：插件仓对照（打包时的静态快照）、测试记录和 JSON 报告（全选复制；错误码只在开发者模式写入）。
- 使用提示：外脑云端和需要平台批准的能力本版只做说明，按钮保持关闭。需要在 Driver「设置 → 开发者」打开开发者模式，再从「App Store → 已安装 → 从本地安装」装入，仅支持 macOS。
- 已知限制：界面只有中文。
- 未验证：真实 Driver 安装后的界面与每个按钮的实际结果。
