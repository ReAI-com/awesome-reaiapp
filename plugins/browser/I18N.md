# Browser 插件语言覆盖清单

`com.reai.browser` 当前源码版本 `1.0.5` 使用同一套资源：`assets/locales/zh.json` 与 `assets/locales/en.json`。Manifest 要求 Host API
`>=1.19.0 <2.0.0` 与能力 `metadata.i18n@1`（开放平台合同只接受 v1 目标集）。

`1.0.4` 增加真实操作反馈、取消和诊断分层。当前候选 `1.0.5` 在此基础上新增 Windows x86_64 目标，尚未平台批准或发布。

## 界面覆盖

主页首屏（引擎说明、打开浏览器/新建标签按钮、快捷方式/当前标签分区标题、刷新
按钮）、标签列表（占位标题「标签 {tabId}」、Agent 徽标、工作标签徽标、关闭标签
的 title 与 aria-label）、空态（还没有打开的标签）、实际操作忙态、失败原因与刷新恢复动作、主页初始化失败 AppError
（`com.reai.browser/HOME_MOUNT_FAILED`）与 bridge 未注入受控错误，全部跟随 Host
语言。

不翻译：真实网页标题与 URL、快捷方式品牌名（Bing、GitHub、知乎、MDN）、
「Agent」徽标。原始错误仅在 Host 开发者模式开启时以普通文本展示，先过滤凭据与 URL 查询参数；关闭开关立即清空并隐藏诊断。
manifest 原始字段保留中文历史默认文字，翻译经 `i18n` 声明投影，不改命令 ID、
权限或审批语义。

## 行为保证

挂载前先读 `ctx.locale.getSnapshot()` 再渲染首屏（英文冷启动直接英文，不闪换）；
`ctx.locale.onChange` 回放快照时 `applyBrowserHomeLocale` 幂等地原位更新文字与
`title`/`aria-label` 属性——不重建 DOM、不重建 Surface，节点、焦点、滚动与活动
Tab 标记全部保留，`browser.*` 桥接调用增量为 0。订阅随 Surface cleanup 释放，
卸载后切语言不再触达插件。未知语言回退英文；插件不持久化自己的语言偏好。
活动标签、tabId、地址输入、URL 与当前页面本身由 Host 引擎持有，语言切换既不
读也不写它们。

## 设计来源

当前设计稿 `design/VoiceType_UI_Designs.html` 的 `PAGE_MAP` 没有 `browser`
路由（仅有 `extstore` 商店页等），即**不存在独立的 Browser 页面设计**；本任务
沿用插件现有界面结构，不新增视觉设计。`#app/extstore` 仅作为商店元数据
（storeListing 各字段）呈现的参考，不虚构 `#app/browser` 设计稿。

## 维护方法

- 改文案：直接编辑 `assets/locales/zh.json` / `en.json`（同键、同 `{name}` 插值、
  非空字符串叶子），运行 `bun run validate`（`reai-app-i18n validate .`）。
- 发候选：bump `app.manifest.json` 与 `package.json` 的版本并同步 `pack` 脚本
  输出名，依次 `bun run validate && bun run build && bun run test:contract &&
  bun run pack`，再解包 `.reaiapp` 复核语言文件与 Build Manifest 摘要。
- 仓库门禁：`bun scripts/verify-official-plugins.ts --plugin browser`（仓库外
  tarball 安装 + 严格语言门禁）与 CI 的 `verify-builtin-plugin-sources.ts`。

## 接口 mock 验证方法

`tests/browser-locale.test.ts`（happy-dom + MockHost）：资源 zh/en 叶子路径与
插值一致性、manifest i18n 声明只引用存在键、`t()` 插值/未知语言回退/缺键回退、
真实视图双语 DOM 与原位更新（节点同一性、焦点保留、占位标题/徽标/aria 重算）、
空态与失败态（普通模式隐藏技术诊断）、bridge 未注入错误双语、挂载失败 AppError 的
userMessage 随 Host 语言且保留 cause。

`tests/contract.suite.ts`（真实 app 代码 + Mock Host）：向 Host bootstrap 同款
bridge 全局键注入受控 `browser.state` fixture（成功两标签 / 空列表 / 抛错），
断言英文冷启动、zh→en→zh 切换、标签行节点与焦点保留、活动标记保留、重复通知
幂等、多实例并发挂载各自跟随语言且逐个销毁不串扰、卸载后无残留订阅，以及
**语言切换期间 bridge 调用增量为 0**。

## 待用户手测项

自动检查不替代以下验收：

1. 真实 Driver 中英文冷启动与前台切语言（含半屏抽屉打开时切换）。
2. 地址栏输入中途切语言：草稿、光标、选区、当前页面与活动 Tab 保留。
3. 详情/首装弹窗中当前五项 Manifest 映射的双语言显示（商店扩展字段未声明 v2 投影）。
4. 引擎真实失败时本地化原因、刷新恢复与开发者开关；诊断仅在开关开启时可见。
