# 浏览器更新日志

## 1.0.5

### 操作过程看得到，失败停在页面上

发布状态：已上架。公开目录当前批准版本为 `1.0.5`（审核时间 2026-10-13，release `44676885-4bc5-4dc3-822b-96b8c55c8be0`，包 SHA-256 `47a11893d18dd0464712fb899426ee820002b65576ae40e668c4786de814406d`，52,307 字节）。本条对比本仓库上一源码版本 `1.0.4-dev.2`。仓库语言说明里更早的已批准版本是 `1.0.3`；`1.0.4-dev.2` 未单独上架。本仓库此前没有浏览器更新日志。公开包与当前源码未做逐字节核对，下列是本仓库源码差异。

- 改进：打开抽屉、新建、切换、关闭标签和读取状态时，页面显示正在进行的操作。进行超过一秒后显示已用秒数。连点同一操作只发出一次请求。
- 改进：操作失败后原因留在页面上，随后的状态刷新不会把失败盖掉。超时、插件停用、未授权和暂时连不上分别提示。普通模式不展示原始错误；开发者模式才显示插件版本、Host 版本和日志位置。
- 改进：离开插件页面会取消还在进行的浏览器操作，迟到的结果不再改页面。「打开浏览器抽屉」命令声明为可取消，并把取消信号交给 Host。
- 变更：安装目标为 macOS（aarch64）与 Windows（x86_64）。公开目录介绍中的使用要求写的是 macOS Apple Silicon 或 Windows x64。
- 变更：不再声明 `storage.kv@1`，也不再使用私有 `state` 存储。增加 `system.tasks@1`，只在开发者模式下读取 Host 版本用于诊断。Host API 仍为 `>=1.19.0 <2.0.0`。
- 未验证：本条目没有附带 2026-10-13 那次审核的 Host 实机记录。
