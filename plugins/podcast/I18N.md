## Manifest 静态元数据

`hostApi.range` 相应提高到 `>=1.19.0 <2.0.0`（v2 能力自 Host API 1.19.0 起支持）。旧 1.0.0 包保持不变。
没有 commands、titlebarStatus、scheduledTasks、permissions、requirements、phaseOneCommitments，因此没有对应目标，不存在缺项。

资源单一来源是 `assets/locales/zh.json` 和 `assets/locales/en.json`。Manifest 默认可读文字与原始贡献 ID

## 插件界面与运行时

| 范围 | 实现 | 验证 |
| --- | --- | --- |
| 播放/暂停、上/下一集、±15 秒、进度条 | `title` 与 `aria-label` 绑定资源；播放按钮标题随播放状态在 render 中取当前语言 | `tests/podcast-view.test.ts`：zh/en 冷启动、zh→en→zh 属性同步 |
| 播放元信息模板 | `view.playerMeta` / `view.episodeMeta` / `view.episodeSources` / `view.episodePlaying` 纯 `{name}` 插值 | 插值一致性测试；包 CLI 校验 |
| 本期提要（kicker/标题/正文/三张卡） | `bindText` 原地更新文本节点，不重建卡片元素 | 合同场景双语结构断言（同一节点） |
| 剧集抽屉（标题、关闭按钮、逐集列表） | 标题与关闭按钮走绑定；剧集行只建一次，状态/文案变化（含切语言与播放 tick）由 `updateEpisodes` 原地写回，不重建行节点；抽屉开合状态跨语言保留 | `tests/podcast-view.test.ts`：行节点身份跨 tick/切语言/切集不变，抽屉状态、关闭动作切语言后仍有效 |
| TBC 逐项标记（5 个 `tbc.*` ID） | `data-tbc-id` 等 ID 不变；`title` / `aria-label` 翻译（`tbc.*` 资源 + `view.tbcAria` 模板） | 冷启动断言 aria 文案；render 重建路径与静态绑定路径分别覆盖 |
| 空态/错误 | 本插件无网络与异步任务；唯一受控错误是启动失败 `view.startupFailed`，经 `surface.fail` 报给 Host | `tests/app-activation.test.ts`：mock 失败路径断言英文报错文案 |
| 内容数据（不翻译） | 集标题（"Today's Briefing" 等）、日期、来源数、时长为静态演示数据，两种语言原样保留 | 英文冷启动无中文 + 中文界面集标题保持原文 双向断言 |

语言接线：`app.ts` 在 `activate` 先读 `ctx.locale?.getSnapshot()` 再注册 surface（先设语言后渲染首屏），
并订阅 `onChange` 同步模块词典；每个视图通过 `onPodcastLocaleChange` 触发一次 render 并在 `dispose` 释放。
render() 全原地：剧集行、播放/暂停图标、集标题/元信息文本节点与各 TBC 标记都只建一次，
render 仅改既有节点的文本/属性/类名；静态节点另由 `bindText` / `bindAttribute` 原地更新。
Runtime `deactivate` 取消订阅。
未知语言（含 `ja` 等任何非 `zh` 值）回退英文；老 Host 没有 `ctx.locale` 时按历史默认中文；插件不持久化语言偏好。
重复语言通知（同值重复 set / onChange 回放）不触发任何更新或渲染。

切语言只更新现有节点的文字与 `title` / `aria-label` / `placeholder` 属性；不重建 Surface 与任何内部节点（回归断言
剧集行/播放按钮 TBC/集标题 TBC 的节点身份不变）、不清输入与滚动、不重启播放、不重置进度、不新增 timer
（受控时钟回归：zh→en→zh 全程 `setInterval` 创建数为 1）。
本插件静态演示本身零业务请求，切语言新增业务调用恒为 0。

## 设计事实

本插件界面来自 `design/VoiceType_UI_Designs.html#app/podcast`（页内锚点，非独立设计文件，无独立设计 hash）；
本轮只替换文案资源，不改动布局、结构与交互。抽屉标题按设计稿英文 "Episodes" 作为英文值，中文为「往期节目」。

## 接口的 mock 验证方法

Podcast 的 Host 接口只有 surface 生命周期（`surfaces.register` / `onIntent` / `ready` / `fail`）与 titlebar intent，
全部为静态演示，无 commands、无网络、无真实音频。验证方式：

- 合同套件（`bun run test:contract`，MockHost 1.19.0）：装→挂载→ready→intent 打开抽屉→卸载后不收 intent；
  场景内用 `host.setLocale("en"/"zh")` 做双语结构断言。
- `tests/app-activation.test.ts`：手写 mock ctx/surface 验证英文快照先于首屏、activate 后切语言对新 Surface 生效、
  老 Host 无 locale 回退中文、挂载失败走 `surface.fail`（含当前语言文案）、重复 activate 与 deactivate 的监听释放。

## 维护方法

- 新增可见文案：先在 `assets/locales/zh.json` 与 `en.json` 同步加语义键（英文键段、无点、纯文本 `{name}` 插值），
  再在视图用 `t()` / `bindText` / `bindAttribute` 消费；不要写第三份词典。
- render() 每次重建的节点（播放按钮、集列表、标题 TBC 标记）用 `t()` 直取；长期存在的静态节点用绑定，销毁时随视图释放。
- Manifest 新增贡献（命令、权限、listing 条目等）必须同步：manifest `i18n.messages` 恰好声明一次新目标 + 两份语言资源各加一键，
  并更新本清单与映射表；目标与资源键不匹配会被 `reai-app-i18n validate` 拒绝。
- 新增语言：添加 `assets/locales/<lang>.json` 并加入 `i18n.locales`；CLI 会按同样完整性检查。Host 当前只发出 `zh/en`。
