# Language coverage

DSH 1.2.7 (Open Platform submission `c8e1d838`, release `4c185caf`) declares `metadata.i18n@1` with v1 targets only, as the Open Platform contract requires.

DSH 1.2.7 is the approved release-builtin artifact; the immutable lock records its exact package digest. It uses `assets/locales/zh.json` and `en.json` for its page, settings, labels, loading/empty states, status explanations, history headings, accessibility text and navigation labels. `app.manifest.json.i18n.messages` maps every supported static target to `metadata`: name, description, main surface, sidebar, settings/refresh action labels and back command.

The initial surface reads the current Host locale after asynchronous data loading. Host changes update existing text/attributes and preserve model selection, focus, scroll and listeners. Cleanup removes the locale listener. Language selection is not persisted by the plugin. Unknown locales fall back to English; a missing legacy Host locale defaults to Chinese.

User/session titles, conversation contents, source names, raw upstream errors, model labels, tool results and runtime diagnostics remain unchanged. Store listing text and requirement/permission descriptions retain historical fallback strings because the current `metadata.i18n@1` target table does not cover them. This package does not claim those Host surfaces are translated.

Validation: 11 view tests (68 assertions), Host contract scenarios including locale/navigation events and unmount cleanup, typecheck, and strict `reai-app-i18n pack` resource/ZIP checks. The package requires Host API 1.18 and `metadata.i18n@1`. Source/package verification is separate from native App acceptance and store approval/publication.
