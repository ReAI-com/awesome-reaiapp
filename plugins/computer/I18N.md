# 电脑操控插件语言覆盖清单

`com.reai.computer` 候选 `0.1.1-dev.1` 使用同一套资源：`assets/locales/zh.json` 与 `en.json`（开发源直接消费，无第二份翻译副本）。Manifest 要求 Host API `>=1.25.0 <2.0.0` 与能力 `metadata.i18n@1`（当前线上送审基线只接受 v1 目标集，见 `docs/plugin-i18n-metadata-v2.md`）。尚未平台批准或发布。

## Manifest 元数据映射

| Manifest 字段 | 原始 ID | 资源键 |
| --- | --- | --- |
| name | — | `metadata.name` |
| description | — | `metadata.description` |
| surface.title | `main` | `metadata.main` |
| sidebar.label | `computer` | `metadata.sidebar` |
| command.title | `com.reai.computer.stop` | `metadata.stopCommand` |

Manifest 原始字段保留中文默认文字；`storeListing` 不在 v1 目标集内，保持原文。

## 界面覆盖

紧急停止条与停止横幅、系统权限卡（标签、状态、引导按钮、刷新）、任务控制台（说明、输入框占位与无障碍名称、开始 / 中止、外发提示、步骤与已用时间、步骤列表与动作描述、任务结果）、模型设置（标题、说明、档位选项、保存中 / 已保存 / 保存失败）、操作审计（标题、刷新、空态、不可用）、通知与诊断提示、设置区底部版本 / 关于入口及信息卡、主页初始化失败 AppError（`com.reai.computer/HOME_MOUNT_FAILED`）、bridge 未注入错误，全部跟随 Host 语言。所有按钮的进行中文案同样覆盖。

## 不翻译

- 用户输入的任务描述。
- 模型输出：步骤思路（thought）、完成 / 放弃说明（detail）。
- 宿主原始错误与模型的非法回复：只在 Host 开发者模式开启时脱敏后作为详情显示。
- 审计记录的动作摘要：由宿主引擎生成，原样显示。
- 发给视觉模型的系统提示词与每步指令：界面语言不得改变 AI 行为。
- 插件更新日志正文：中文撰写，界面附语言说明。
- 品牌与协议标识：「Agent」、「Computer Use」、模型档位 ID、appId、错误码。

## 行为保证

挂载前先读 `ctx.locale.getSnapshot()` 再渲染首屏（英文冷启动直接英文，不闪换）；`ctx.locale.onChange` 回放时 `applyLocale` 幂等地原位改写文字与 `placeholder` / `aria-label` 属性，不重建 DOM、不重建 Surface，输入框内容、焦点、步骤列表与进行中的任务全部保留，不重复任何 `computer.*` 或云模型调用。任务结果、步骤错误与通知以「资源键 + 参数 + 原文」结构保存，切换语言时重新渲染，原文不变。订阅随 Surface cleanup 释放。未知语言回退英文；插件不持久化自己的语言偏好。

## 已验证与未验证

已验证（代码级）：资源键与插值一致、`reai-app-i18n validate/build/pack`、最终包内两个资源文件与 Build Manifest 摘要、视图中英文 DOM 与原位切换、整插件经 MockHost 冷启动英文后切换中文、挂载失败 AppError 双语、源码硬编码中文扫描。

未验证：真实 App 中的中英文显示与 Host 元数据投影（需经平台审核从商店安装）、翻译质量的人工复核、实机冷启动 / 后台恢复 / 关闭再打开的切换表现。
