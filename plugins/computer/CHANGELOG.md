# 电脑操控更新日志

## 0.1.1-dev.1 · 2026-10-20

### 让 Agent 在你的注视下操作这台电脑

状态：本地源码候选，未送审、未签名、未上架。此前没有公开发布过的版本，本条按初版功能撰写。

在系统设置里手动开启辅助功能和屏幕录制权限后，可以用一句话描述任务，由 Agent 看屏幕、点击和输入来完成。全程可见，随时可以紧急停止。

- 新增：权限引导。检测辅助功能与屏幕录制是否已开启，并引导到系统设置；屏幕录制只检测与引导，不会替你申请。
- 新增：紧急停止。可在插件页或宿主命令「紧急停止电脑操控」中触发，停止后所有鼠标键盘操作立即被拒绝，按住的鼠标按键会被抬起；只有你在插件页点「恢复操控」才会解除。
- 新增：任务控制台。每一步截取屏幕交给云端视觉模型判断下一步，单个任务最多 20 步，出错即停，可随时中止。
- 新增：操作审计。列出每一次截图、点击、输入的来源与结果。
- 新增：设置区底部显示当前版本，可查看本版本更新日志和插件信息。
- 修复：中止任务或离开插件页面时，不再顺带解除紧急停止；从插件页或宿主命令紧急停止时，会同时结束正在进行的任务，恢复操控后旧任务不会接着执行。
- 使用提示：执行任务时，每一步的屏幕截图与任务描述会经登录账号的云端模型网关发送给视觉模型；插件不接触任何 API Key。请勿在屏幕上显示不希望外发的内容时运行任务。
- 已知限制：Agent 与你共用同一套鼠标和键盘，任务运行时请不要操作电脑；屏幕上的文字可能误导模型，发送消息、删除等操作前暂无二次确认。
- 未验证：真实宿主中的安装、权限授予与点击执行，云端模型实际识别效果，Windows 平台，平台审核、签名与公开发布。
