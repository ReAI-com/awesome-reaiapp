# Language coverage

Pi Agent 1.0.3 (Open Platform submission `5c005a9b`, release `0a60ea73`) declares `metadata.i18n@1` with v1 targets only, as the Open Platform contract requires.

Pi Agent 1.0.3 is the approved release-builtin artifact; the immutable lock records its exact package digest. It uses `assets/locales/zh.json` and `en.json` for its page, settings, labels, empty/loading states, status explanations, accessibility text and navigation labels. `app.manifest.json.i18n.messages` maps every supported static target to `metadata`: name, description, main surface, sidebar, settings action label/text and back command.

The settings badge reports the Host login state and the number of configured model tiers. It does not report cloud connectivity, subscription access or a successful model request.

The initial surface reads the current Host locale after asynchronous data loading. Host changes update existing text/attributes, retaining inputs, focus, selection, scroll and listeners. Cleanup removes the locale listener. Language selection is not persisted by the plugin. Unknown locales fall back to English; a missing legacy Host locale defaults to Chinese.

User titles, prompts, tool results, model catalog labels, workspace paths and upstream diagnostic details remain unchanged. Brand/protocol identifiers remain stable. Store listing text and requirement display/remediation text retain historical fallback strings: they are outside the current `metadata.i18n@1` target table. This package does not claim those Host surfaces are translated.

Validation: 10 view tests (94 assertions), Host contract scenarios including locale events/navigation and unmount cleanup, typecheck, and strict `reai-app-i18n pack` resource/ZIP checks. The package requires Host API 1.18 and `metadata.i18n@1`. Source/package verification is separate from native App acceptance and store approval/publication.
