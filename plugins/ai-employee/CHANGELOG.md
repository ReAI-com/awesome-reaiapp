## 0.2.0 · 2026-10-08

状态：本地源码候选，未送审、未签名、未上架。

- 使用通用 AI 员工应用结构。Dashboard 与岗位看板由 HTML、CSS 和声明式数据绑定定义；财务、人事仅为公开示例，新岗位复用同一核心。
- Agent 改为右侧非模态面板。左侧工作内容保持可操作，引用卡片在左侧打开原件、报告和页面。关闭再打开保留当前界面实例的对话与草稿，不增加会话管理。
- 看板导航 `+` 预填页面请求，不自动发送。Agent 输出有界页面提案，用户确认后保存，按岗位隔离并保留提案与配置来源。页面读取实时标准数据；普通数据变动不使草稿失效，确认时岗位不一致或配置版本变化需要重新生成。
- 页面支持指标、记录表与报告列表，以及有界字段筛选和单位一致的基础指标差额。新增页面每岗位最多20个、全库最多100个。本期不提供看板隐藏、删除或排序管理。
- 通过已有可选 Voice 服务添加语音输入接口。麦克风、权限和转写由 Host / Voice 处理；结果只填草稿。浏览器预览禁用录音，真实设备与 Voice 未验收。
- `0.2.0` 对旧配置与缺少页面索引的数据使用只读兼容，不改写来源或重解释记录。不兼容旧模板使用通用字段展示，原配置继续保留。`rollbackFloor` 设为 `0.2.0`，`0.1.0` 不能读取新的页面配置，未执行 migration。
- 开发模式继续锁定岗位结构、提示词、Skill、SOP 与默认展示配置。配置导出仅含静态定义；运行时新增页面、公司资料与密码不进入新插件模板。
- 验证覆盖声明式页面校验、持久化、岗位隔离、配置过期、重复确认、旧索引 CAS、零孤立对象正常路径与失败写入保留。完整构建、合同、浏览器和新岗位生成结果分别记录。平台批准、签名、真实 Host 安装、真实模型、真实语音和公开发布未验证。

## 0.1.0 · 2026-10-08

状态：本地开发 Demo，未送审、未签名、未上架。

- 新增原始资料、标准记录与岗位 Agent 的三阶段工作台。提供财务与人事配置、字段校验、来源关联和报告草稿。
- 原始资料保存原始字节与 SHA-256 标识。标准记录支持人工修改、归档、修订历史和刷新后恢复。
- 设置页集中通用配置。开发模式使用自设密码解锁，支持岗位结构、提示词、inline Skill、SOP 和受限制的 HTML / CSS 展示配置。
- 提供岗位配置导出与新插件生成命令。生成器替换插件身份和默认岗位，不复制用户数据、密码或构建产物，不覆盖已有输出目录。
- 提供外部资料适配接口，支持有界的原始字节批量入库和同内容重试去重。当前未连接真实外部来源，也未提供后台调度。
- 默认分析使用明确标记的规则演示。另提供 Agent Service v2 适配器和本地未批准候选准备命令，保留平台批准与用户允许门禁。
- 验证范围：本地源码验证与交互验收分别记录。PDF / 办公文档提取、OCR、邮箱与定时采集、云端数据库、语音、真实模型、平台审核、签名、Host 安装和公开发布未验证。
