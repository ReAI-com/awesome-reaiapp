# Codex Link 更新日志

## 0.5.13

### 支持 Windows 安装目标

候选状态：未发布。公开目录当前批准版本仍是 `0.5.12`。本条只对比本仓库上一源码版本 `0.5.12`。

- 变更：安装目标在 macOS（aarch64）之外增加 Windows（aarch64 / x86_64）。权限、Host API（`>=1.19.0 <2.0.0`）以及对本机 Codex app-server 的依赖不变。插件仍只消费 agent 协议，本身不做推理。
- 未改：从胶囊或 Tab 层打开正在等待的对话，行为与 `0.5.12` 相同，见下条。
- 未验证：Windows 真机上的安装、连接本机 Codex、审批与 Tab 层跳转；平台审核、签名与公开发布。

## 0.5.12

### 从 Tab 层打开正在等你的对话

发布状态：已上架。公开目录当前批准版本为 `0.5.12`（审核时间 2026-09-26，release `c295d5b1-e416-4fa4-a68f-b32d9afaab19`，包 SHA-256 `96c39b76c6a2b3c9fb39b6dcf3aefc8a9daa8fd833ffa4037a5730cd5ed57345`，234,375 字节）。该摘要与本仓库 2026-10-03 源码交付记录中的 `0.5.12` 包一致。本仓库此前没有 Codex Link 更新日志，本条不补写相对 `0.5.11` 的完整差异。`0.5.11` 因商店文案走了平台当时不接受的 i18n 目标被拒，未上架。

- 已有：Codex 里有对话在等你时，从 Host 的胶囊或 Tab 层待办点开，会打开那条会话。快照里已经有它就直接进入详情；还没有就先等，大约 30 秒内到达才打开，超时留在列表，不凭空打开一张详情。详情真正出现后回报宿主，胶囊、Tab 层和通知按「已看过」撤卡。
- 使用提示：需要本机运行的 Codex app-server。公开目录介绍写的安装范围是 macOS Apple Silicon。`0.5.13` 才在源码里增加 Windows 安装目标，该目标尚未上架。
